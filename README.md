# CreateX

CreateX is a full-stack **MERN social media application** that allows users to create posts, upload images, and explore content through a modern and responsive feed.

### Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Image Upload & Storage:** Multer, ImageKit
* **API:** REST API

### Key Features

* Create and view social media posts
* Upload and store images
* Dynamic social media feed
* CRUD operations
* REST API integration
* Responsive user interface
* Frontend–backend integration

CreateX demonstrates practical full-stack development concepts including **CRUD operations, REST API development, file handling, image storage, state management, database integration, and responsive UI design**.
